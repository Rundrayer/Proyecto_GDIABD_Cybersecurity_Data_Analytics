GUÍA DE INSTALACIÓN, LIBRERÍAS Y APRECIACIONES DE EJECUCIÓN DEL PROYECTO

Proyecto Integrador: Cybersecurity Data Analytics


--PROGRAMAS
--------------------------------------------------------------------------------
1.Python Versión 3.10 o 3.11.

2.Entorno de ejecución: Anaconda / Jupyter Notebook o Visual Studio Code con soporte para Jupyter.

3.Java Development Kit: Versión 11 o 17 como requisito obligatorio para ejecutar Apache Spark.

4. Hadoop y si se ejecuta en Windows de forma local, se necesita los Binarios winutils.exe y hadoop.dll correspondientes a la versión de Hadoop utilizada por Spark.

Los cuales se usaron para esta versión del proyecto. (puede cambiar la dirección de ruta de los binarios en configuraciones.py)
